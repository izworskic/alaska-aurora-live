What this score means

The 0–100 number is our viewing score, not a percent chance. It combines current NOAA space-weather signals with local NWS sky cover, darkness, moonlight and viewing thresholds for the selected Alaska region.

Alaska Regional Outlook

Alaska sits under and near the auroral oval, so even modest geomagnetic activity can produce displays. Summer daylight is often the limiting factor.

How to use this tonight

1. Start with the headline and score. 2. Check cloud cover and the best dark window. 3. Use the regional cards to decide whether driving north or toward darker sky is justified. 4. Before leaving, check NOAA's official 30-minute aurora forecast.

In Alaska, darkness can matter more than Kp in late spring and summer. The tool suppresses a numeric viewing score when there is no useful darkness.

Data and truth boundaries

NOAA OVATION is a short-term modeled aurora signal. Kp is a broad geomagnetic index. Neither is a local sighting probability. A display can be hidden by clouds, twilight, moonlight, light pollution, terrain or a blocked northern horizon. Missing live values remain missing; this tool never converts missing data into a reassuring zero.
