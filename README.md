# Alaska Aurora Live

Independent state aurora decision tool modeled after the successful Michigan Northern Lights experience.

- Canonical: `https://chrisizworski.com/national-tools/aurora/alaska/`
- Default region: `fairbanks`
- Runtime: Vercel static HTML + Node serverless API
- Primary sources: NOAA SWPC, NWS API, U.S. Naval Observatory
- No database and no paid API required
- No runtime dependency on the Michigan repo

## Commands

```bash
npm test
npm run build
```

## Preservation

This repository is intentionally independent of `izworskic/chrisizworski-com`. Do not modify or redirect the Michigan Northern Lights canonical as part of this product.
